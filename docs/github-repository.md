## README emphasis

The README should lead with the live landing page, reviewer quick path, core product workflow, and environment strategy. Keep implementation details visible, but make the first screen answer:

- what BrokerOps is
- who it is for
- how to see the product
- how to validate the platform locally
- which commands create meaningful AWS cost

## Tradeoff

The Cloudflare Pages URL presents the end-user surface, while the AWS API path remains environment-aware and cost-controlled. The GitHub About link should point to the landing page because it is the fastest way for a reviewer or hiring manager to understand the product before reading infrastructure details.
