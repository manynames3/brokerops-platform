# Evidence

This folder is for operational proof captured during preview and production validation.

Recommended artifacts:

- architecture diagram
- Terraform plan summary
- CI check output
- ECS service health
- target group health
- blue-green rollout notes
- smoke test output
- CloudWatch alarm configuration
- PostgreSQL query plan before and after tuning
- cost-control notes
- teardown verification output

Generated evidence can be written to `docs/evidence/generated/`.
